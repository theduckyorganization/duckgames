# Duck Games Arcade V3

Website trò chơi vịt dành cho trẻ em và gia đình, chạy trực tiếp trên GitHub Pages.

## Nội dung

- 6 game cho trẻ dưới 5 tuổi: Tìm Vịt Vui, Cho Vịt Ăn, Đếm Vịt Con, Ghép Màu, Mặc Đồ Cho Vịt và Tắm Cho Vịt.
- 6 game cho trẻ 5–14 tuổi: Ghép Đôi Cảm Xúc, Lucky Duck Shoot, Mê Cung Vịt, Toán Nhanh, Đua Vịt Gõ Chữ và Nhịp Điệu Quack.
- Cột danh sách game bên trái; tự thu gọn trên điện thoại.
- Có âm thanh đơn giản, tính điểm và giao diện cảm ứng.

## Cập nhật website trên GitHub

1. Giải nén file ZIP.
2. Xóa hoặc ghi đè các file cũ trong repository bằng toàn bộ nội dung đã giải nén.
3. Phải giữ nguyên thư mục `assets` và file `assets/duck-stickers.png`.
4. Chờ GitHub Pages cập nhật khoảng 2–10 phút.

Các file `index.html`, `style.css` và `script.js` phải nằm ngay ngoài cùng của repository, không đặt trong một thư mục con khác.
